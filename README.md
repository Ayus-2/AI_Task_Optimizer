# Amdox AI-Powered Task Optimizer

An AI-based employee productivity and wellness system that analyzes emotions and recommends suitable tasks based on mood and behavior patterns. The project combines machine learning, emotion analysis, and data visualization to create a smarter and healthier workplace environment.

## Features

* Real-time emotion detection
* Facial expression analysis
* Text sentiment analysis
* Task recommendation system
* Stress and burnout alerts
* Historical mood tracking
* Team mood analytics dashboard
* Secure data handling and privacy protection
* Interactive UI with charts and analytics

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* OpenCV
* DeepFace
* TensorFlow
* Streamlit
* Matplotlib
* Seaborn

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Emotion Detection
4. Sentiment Analysis
5. Task Recommendation
6. Dashboard Visualization
7. Alert Generation

## Installation

```bash
git clone https://github.com/Ayus-2/AI_Task_Optimizer.git
cd AI_Task_Optimizer
pip install -r requirements.txt
streamlit run app.py
```

## Project Objective

The main objective of this project is to improve employee productivity and mental well-being by using AI-driven emotion analysis and intelligent task allocation.
